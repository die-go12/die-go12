### 🧠 Mi Filosofía de Desarrollo
Me enfoco en escribir software que no solo funcione, sino que sea mantenible y seguro:

- 🛡️ **Security First:** No dejo credenciales en el código (Variables de Entorno > Hardcoding).
- 🧼 **Clean Code:** Escribo código para humanos. Nombres claros y funciones pequeñas.
- 🏗️ **Arquitectura:** Prefiero el diseño sólido (POO) sobre los parches rápidos.
- 🤝 **Trabajo en Equipo:** Documentación clara y commits semánticos.
